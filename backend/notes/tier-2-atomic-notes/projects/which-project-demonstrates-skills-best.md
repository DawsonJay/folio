# Which Project Best Demonstrates My Skills

## First Choice: Folio

Folio - this portfolio chatbot - is my first choice. It's a creative idea that took a range of skills to make and uses clever mechanics to increase reliability and reduce cost.

**Technical range**: AI/ML capabilities (RAG systems, semantic search with embeddings, prompt engineering), full-stack development (FastAPI backend, React frontend), system design (atomic notes architecture, retrieval pipeline), testing and iteration (test-driven development with measurable metrics).

**Problem-solving**: Creating a maintainable, accurate, cost-effective knowledge base rather than expensive LLM calls with huge context windows. The atomic notes system with semantic search creates a knowledge base that's maintainable, accurate, and cost-effective.

**Creative approach**: Most portfolio websites are static pages. Folio makes the portfolio itself an AI-powered interactive experience showing AI capabilities while being genuinely useful for evaluating my work.

## Second Choice: Integrations Dashboard

The Integrations Dashboard - production reliability and long-term thinking. Built 3+ years ago, it's still running with zero maintenance, zero bug reports, serving 15+ sales team members daily.

**Longevity proof**: That longevity came from solid architecture, clean code, and thinking about maintainability from day one, not just shipping features. Production systems that last years without maintenance are rare.

**Full-stack ownership**: I owned the entire product - designed the UI, built the React/TypeScript frontend, implemented backend features, made all architectural decisions.

## Why These Two

Folio demonstrates breadth and creativity. Integrations Dashboard demonstrates production reliability and long-term thinking. Together they show I can both explore new technologies creatively and build stable systems that last.
