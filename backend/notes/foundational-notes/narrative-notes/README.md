# Narrative Notes - Overview

This folder contains narrative notes extracted from existing atomic notes, portfolio-profile records, and linked-in-job-hunter documentation. These notes provide the "why" and "how" behind factual information, helping the LLM generate more engaging, personal responses.

## Purpose

Narrative notes complement factual notes by:
- Providing rich context, storytelling, and detailed explanations
- Including emotions and motivations, not just facts
- Showing the journey, not just the destination
- Connecting to broader themes and values
- Making responses more engaging and authentic
