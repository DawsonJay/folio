# Narrative notes — overview

This folder holds **story-driven** markdown: motivations, trade-offs, and how work *felt*, to support natural answers without duplicating raw facts (those live in `../factual-notes/`).

## Purpose

- Capture voice, anecdotes, and “why” behind decisions
- Cross-link topics (projects, immigration, teamwork) for consistent storytelling
- **Filenames in this directory are the source of truth** — long static file lists go stale quickly

## How to use

1. When a story changes (new role, new project chapter), update the relevant narrative file.
2. Fold any facts that must be recruiter-accurate back into factual notes or Tier 1 direct answers.
3. Re-run embedding scripts if Tier 2 atomic notes pull from this content.
