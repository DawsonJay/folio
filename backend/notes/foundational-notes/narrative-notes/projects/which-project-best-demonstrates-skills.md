# Which Project Best Demonstrates My Skills

## First Choice: Folio

If I had to pick one project that best demonstrates my skills, it would be **Folio** - this portfolio chatbot you're talking to right now.

**Why Folio stands out**: It's a creative idea that took a range of skills to make and uses clever mechanics to increase reliability and reduce cost.

**Range of skills demonstrated**:
- **AI/ML**: RAG systems, semantic search with embeddings, prompt engineering, quantitative evaluation of AI systems
- **Full-stack development**: FastAPI backend, React frontend, integration between components
- **System design**: Atomic notes architecture, retrieval pipeline, context management
- **Testing and iteration**: Test-driven development with measurable metrics, iterative improvement based on data
- **Problem-solving**: Solving the "portfolio that answers questions" problem with clever architecture rather than expensive API calls

**Clever mechanics**: The atomic notes system with semantic search creates a knowledge base that's maintainable, accurate, and cost-effective. Instead of relying entirely on expensive LLM calls with huge context windows, the system retrieves only relevant information and constructs focused responses. This makes it practical to run while maintaining quality.

**Creative approach**: Most portfolio websites are static pages or traditional formats. Folio takes a completely different approach - make the portfolio itself an AI-powered interactive experience that demonstrates AI capabilities while also being genuinely useful for both me and people evaluating my work.

## Second Choice: Cirrus

My second choice would be **Cirrus**, even though it was a failed project that I ultimately cancelled.

**What Cirrus demonstrates that Folio doesn't**: Using creativity to get around basic constraints such as costs or lack of resources. When I couldn't afford professional weather APIs or commercial datasets, I found ways to work with free data sources, built sophisticated interpolation systems, and designed architectures that worked within severe resource limitations.

**Why a failed project matters**: Cirrus demonstrates that I can recognize when a project is mis-scoped and make the difficult decision to stop rather than following sunk costs. It also shows how I learn from failure - the lessons from Cirrus directly informed how I scoped WhatNow and other subsequent projects to be realistic rather than overambitious.

**Technical creativity under constraints**: The spatial interpolation algorithms, KD-tree indexing, genetic algorithms for model evolution - all of these came from needing to work around not having the ideal data or resources. Constraints forced creative technical solutions.

## Why These Two Together

**Folio** shows I can complete ambitious projects using modern AI technology and deliver production-quality systems that work reliably.

**Cirrus** shows I can work creatively under constraints and learn from failure to make better decisions in future projects.

Together they demonstrate both the ability to ship successful AI-powered applications and the judgment to know when to persist versus when to pivot.

## What About Other Projects?

**WhatNow** would be my third choice - it demonstrates end-to-end ML system design, contextual bandits implementation, and building systems that generate their own training data. It's a production application I actually use, which proves real-world value.

**Integrations Dashboard** demonstrates long-term reliability and zero-maintenance architecture. Three years in production with no bugs shows I can build stable, well-architected systems.

**moh-ami** demonstrates LLM integration, TypeScript type safety across the stack, and intuitive UI/UX design for complex functionality.

But if forced to pick one project for "best demonstrates my skills," it's Folio. If I can pick a second to show a different dimension, it's Cirrus.
