# Factual Notes - Overview

This folder contains factual notes extracted from existing sources. These notes serve as a single source of truth for key information that will be used to create direct answer notes.

## Purpose

These factual notes are:
- **Comprehensive**: Covering all key areas of information
- **Accurate**: Extracted from existing atomic notes and documentation
- **Structured**: Organized by category for easy reference
- **Gap-Marked**: Clearly indicating where information is missing or needs verification

## Files Created

### 1. languages-technologies.md
- All programming languages, frameworks, libraries, and tools
- Proficiency levels, years of experience, usage contexts
- Projects where each technology was used
- **Gaps**: Many dates and proficiency levels need to be filled

### 2. work-experience.md
- Complete employment history with dates
- Roles, responsibilities, and projects at each position
- Team sizes, technologies used, outcomes
- **Gaps**: Some project dates, team sizes, and current statuses need to be filled

### 3. projects.md
- All personal and professional projects
- Technologies, timelines, deployment links
- Key features and outcomes
- **Gaps**: Many project start/end dates need to be filled

### 4. education-certifications.md
- All education history with exact dates
- Certifications and qualifications
- Academic performance details
- **Gaps**: Some course details and additional certifications may be missing

### 5. immigration-canada.md
- Complete immigration path and timeline
- Visa status and requirements
- Relocation plans and commitment
- **Gaps**: Some specific dates and details need to be filled

### 6. skills-competencies.md
- Technical and soft skills with evidence
- Proficiency levels and project examples
- **Gaps**: Some proficiency levels and evidence need to be completed

### 7. personal-background.md
- Personal information and timeline
- Career journey and transitions
- Background experiences
- **Gaps**: Some dates and details need to be filled

## How to Use These Notes

1. **Review Each File**: Go through each file and review the extracted information
2. **Fill Gaps**: Complete all sections marked with `[GAP]` or `[ ]`
3. **Verify Accuracy**: Check dates, names, and facts against original sources
4. **Add Missing Information**: Include any information that wasn't captured
5. **Update as Needed**: Keep these notes current as facts change

## Next Steps

Once these factual notes are complete and verified:
1. Use them as the foundation for creating direct answer notes (Tier 1)
2. Reference them when creating narrative notes (Tier 3)
3. Ensure consistency across all note types
4. Update them as new information becomes available
