# Tell me about a project you led as technical lead

Yes — twice at Nurtur, in different ways.

On Nexus Dashboard (Oct 2025–Feb 2026), I was technical lead. I drove architecture decisions, defined API contracts, and optimized performance from 15+ seconds to sub-5 seconds. I had a senior developer I reported to, but I owned the day-to-day technical direction. The architecture I designed adapted to backend changes without requiring frontend rewrites.

On Email Editor (2024–2025), I led frontend architecture and mentored 3 backend developers transitioning into full-stack roles. Regular code reviews, pair programming, explaining the "why" behind decisions so they could make similar calls independently. When I moved off that project, the team continued successfully — because I'd built their capability, not created dependency on me.

My style is enabling rather than controlling. Leadership is taking ownership, guiding direction, and elevating the people around you — not the job title.
