# Tell me about a time you had to meet a tight deadline

Building Folio — the RAG-powered portfolio chatbot you're talking to right now — under real pressure. Not a theoretical project. Essential for my job search: I needed it working and deployed so I could start applications.

The challenge was balancing quality architecture with speed. My approach: build a solid foundation that can grow, but define a strict minimum viable scope so something real ships fast. I think of it like a trellis for a seedling — not too small to break under the first bit of growth, but not over-engineered for a plant that hasn't grown yet.

For Folio, that meant the RAG system, embedding storage, and API had to be built correctly from day one — those were too expensive to rewrite. But I didn't need every feature immediately. The MVP had to actually work: real retrieval, real answers, real deployment. Not a prototype.

It's now live, continuing to evolve, and the trellis is holding. That's how I approach any tight deadline: right structure, viable version, iterate.
