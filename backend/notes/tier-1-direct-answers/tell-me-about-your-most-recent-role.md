# Tell me about your most recent role

Full Stack Developer at Nurtur, July 2022 to February 2026 — 3.5 years across three major projects.

I started with the Integrations Dashboard: my first four months, first task as a new hire, sole frontend developer learning backend under senior mentorship. I rebuilt a barebones internal page into a full-stack dashboard the sales team uses every day. It's been running three years without a maintenance call. That project set the standard I've tried to hold myself to since.

By the time I reached Nexus — a dashboard visualising complex backend infrastructure — I was the technical lead on the frontend side. The initial load time was 15+ seconds. I rearchitected the data flow: strategic loading, React Query caching, buffer systems, progress feedback. Sub-five seconds. I also designed the foundation blocks architecture so the dashboard could absorb backend changes without frontend rewrites, which mattered because the backend structure was moving throughout the project.

The Email Editor was a four-person team rebuild of the core product — a drag-and-drop template system for client email campaigns. I built complex components including a link editor using Lexical. Throughout all three projects I mentored three backend developers transitioning to full-stack roles and conducted regular code reviews.

The team was restructured in February 2026.
