# What did you do at Nurtur?

The day-to-day was primarily React and TypeScript — that was the constant across all 3.5 years. I was the frontend developer on internal tooling and then on the core product, with full-stack responsibilities that meant picking up backend work in C# and Azure Functions when it was needed.

The cadence looked like: build a feature branch, get it reviewed, review other people's code, iterate. Code reviews were a regular part of the week rather than an afterthought. As the team grew and changed, I increasingly found myself being the person that newer developers came to with questions — that eventually formalised into mentoring three backend developers as they transitioned into full-stack work.

The work I touched over those 3.5 years: the Integrations Dashboard (my first project, sole frontend developer learning backend under mentorship), the Nexus Dashboard (technical lead on the frontend, performance optimisation from 15+ seconds to sub-5), and the Email Editor (four-person rebuild of the core product, complex component work using the Lexical framework).
