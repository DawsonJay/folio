# What was your first programming project?

My first programming projects were half-formed games I made following along with books, Codecademy, and Udemy courses. I started teaching myself coding in July 2014 after leaving art university, learning Java, Python for Arduino projects, and C# for Unity game development.

These early projects were clumsy and never reached completion, but they taught me the fundamentals. Following tutorials meant I could build something functional quickly, even if I didn't fully understand every line. The half-formed nature was actually useful - I'd follow a tutorial halfway, get the core mechanic working, then abandon it to start something new. This rapid iteration through many small projects built foundational skills faster than polishing one project to completion.

The pattern from those early days - build quickly, learn from doing, move to the next challenge - still defines how I learn. I taught myself all my coding languages through projects I wanted to build, not through structured curricula. That goal-driven, hands-on approach works for me.

My first professional project was the Integrations Dashboard at Nurtur in July 2022, built 4 months after finishing the Ironhack bootcamp. That was the first project where everything came together - clean architecture, production quality, real users depending on it daily. It's still running 3+ years later with zero maintenance.
