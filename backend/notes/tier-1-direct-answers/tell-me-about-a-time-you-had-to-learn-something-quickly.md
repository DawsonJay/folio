# Tell me about a time you had to learn something quickly

When I built moh-ami, I needed to learn several technologies I hadn't used before: Next.js 14 App Router, GraphQL with Apollo Server, and Prisma ORM. I had React and TypeScript, but the rest was new.

My approach to learning quickly is to read enough to start, then build something real and let the problems teach me. I understand schema design and resolver implementation now because I implemented a GraphQL API, not because I read documentation about it first. Same with Prisma — I learned it by using it for actual database migrations, which meant the knowledge stuck.

The technical decisions I made quickly: Next.js 14 App Router over Pages Router for modern React patterns, GraphQL over REST because the translation data structure had complex relationships that benefited from flexible querying, and the LLM integration sent the full English text in a single structured request rather than processing line by line — more efficient and the model understands context better that way.

The project went from nothing to production-deployed in a single intensive day on January 11, 2026. The speed came from knowing which decisions mattered and which ones I could make quickly and adjust later.
