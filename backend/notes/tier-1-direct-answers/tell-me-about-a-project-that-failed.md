# Tell me about a project that failed

Cirrus — a Canadian weather AI prediction system. Machine learning, spatial data processing, complex visualization. Cancelled before completion.

The data killed it. 31% precipitation coverage. 0% wind speed and humidity. Temperature was fine at 83%, but the gaps in the other fields made meaningful prediction impossible. Interpolation logic failed to find available stations, and significant data was lost in processing. The system could run, but the output wasn't trustworthy.

The cancellation decision was the right call. Weather prediction is hard for professional meteorological organizations with large teams. Solo, with fragmented public data, wasn't a solvable problem at the scope I'd scoped it. I stopped when evidence showed the fundamental premise — that I could source sufficient data — was wrong.

What carried forward: spatial data processing concepts informed Atlantis's mapping system. The ML fundamentals powered WhatNow's recommendation engine and moh-ami's AI features. None of it was wasted — just redirected to more achievable scopes.

The lesson I carry: ambitious scope requires honest data validation early. The sunk cost fallacy is real. Stopping and extracting what's valuable is judgment, not failure.
