# What's your experience with Git?

Git has been part of my workflow since my Ironhack bootcamp in May 2020 and every professional role since. It's not something I think about much anymore — the habits are built in.

In team settings at Nurtur, the workflow was branch per feature, pull request for review, merge after approval. I conducted regular code reviews through that process and mentored backend developers on Git practices as they moved into full-stack work — things like writing commit messages that explain why rather than what, keeping branches short-lived, and using PRs as documentation of decisions rather than just a merge mechanism.

I'm comfortable with rebasing, cherry-picking, resolving complex merge conflicts, and the various situations where you need to be surgical about history. The practical skill that comes up most is knowing when to keep history clean versus when it's not worth the overhead — for collaborative work on a shared codebase, clean history matters; for a solo personal project with no one else reading it, less so.
