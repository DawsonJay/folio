# How did you grow in your position at Nurtur?

I joined Nurtur in July 2022 as a Full Stack Developer. My first project was the Integrations Dashboard - I was the sole frontend developer and learned backend implementation under senior mentorship. By the time I left in February 2026, I was the technical lead on Nexus Dashboard, mentoring 3 backend developers transitioning to full-stack roles, conducting code reviews, and providing technical guidance on React/TypeScript architecture.

Growth came through taking ownership of increasingly complex projects. Integrations Dashboard taught me production full-stack development while learning under senior mentorship. Email Editor (2024-2025) taught me large team collaboration, Redux state management, and complex framework integration (Lexical). Nexus Dashboard (Oct 2025-Feb 2026) was my first technical lead role - I drove architecture decisions, chose API contracts and data structures, and led the technical implementation with senior oversight.

I went from implementing features to architecting systems. For Nexus, I designed the frontend architecture to adapt to backend changes without significant rewrites, reduced dashboard load time from 15+ seconds to sub-5 seconds through strategic loading and caching, and created comprehensive documentation for future developers.

My role evolved to include mentoring and technical leadership. I taught CSS and frontend concepts to backend developers, conducted regular code reviews with educational feedback, and bridged gaps between technical and non-technical teams (backend engineers and sales teams). This growth from junior individual contributor to trusted mentor and technical guide happened organically as I proved capability and reliability.
