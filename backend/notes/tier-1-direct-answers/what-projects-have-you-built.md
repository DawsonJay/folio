# What projects have you built?

I've built several projects that demonstrate different aspects of my skills. My most significant professional project is the Integrations Dashboard I built at Nurtur. It's been in production for over 3 years without any maintenance, crashes, or bug reports. The sales team uses it every day, and they still express gratitude for it years later. I also worked on the Nexus Dashboard, optimizing performance from 15+ seconds to under 5 seconds, and the Email Editor, where I mentored backend developers transitioning to full-stack roles.

On the personal project side, I've built WhatNow, an AI-powered activity recommendation system using contextual bandits, which is a form of reinforcement learning. It's a production-deployed application that I actually use in my daily life. The system uses semantic embeddings to match user context with activities and continuously improves over time based on user feedback.

I've built moh-ami, a French learning translation tool with LLM integration. It provides detailed educational explanations for language learners, not just simple translations. The system uses OpenAI's GPT-4o-mini for structured prompts that produce consistent JSON schema outputs, handling word-by-word mappings, grammar explanations, and cultural context.

I'm working on Atlantis, a lake bed mapping system that demonstrates hardware and embedded systems skills. It's a remote-controlled surface boat that tows a weighted probe equipped with eight ultrasonic sensors. The system uses LoRa long-range communication and GPS positioning to create highly accurate 3D maps of lake beds.

I'm also building Folio, the RAG-powered portfolio chatbot you're talking to right now. It uses LangChain for RAG orchestration, handles retrieval, prompt construction, and response generation. The system uses embeddings for semantic search and integrates with OpenAI for generating responses.

I've also worked on projects that didn't complete but taught valuable lessons. Cirrus was a Canadian weather AI prediction system that I cancelled due to data quality issues, but it taught me about project scoping and when to pivot. Jam Hot was a computer vision project that failed due to dataset quality, but it led to insights that informed WhatNow's architecture.

All of these projects demonstrate different skills - full-stack development, AI/ML integration, system architecture, performance optimization, and hardware-software integration. They show my ability to take projects from concept through production deployment.
