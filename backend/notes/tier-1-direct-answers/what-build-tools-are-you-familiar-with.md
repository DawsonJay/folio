# What build tools are you familiar with?

Vite is my primary build tool for the past two years — it's been the right choice for personal projects like WhatNow, moh-ami, and Folio where fast iteration matters. The dev server startup time and hot module replacement make a real difference when you're in an active development cycle.

I have webpack experience from my bootcamp and earlier projects. The two tools occupy the same conceptual space — bundling, code splitting, asset optimisation, environment-specific configuration — and the underlying concepts transfer. Vite's speed advantage in development is significant enough that I'd default to it for new projects, but I'm comfortable with webpack in a codebase that already uses it.
