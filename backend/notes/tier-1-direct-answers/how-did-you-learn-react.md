# How did you learn React?

I learned React through the Ironhack bootcamp in May 2020, then built real projects immediately after. The bootcamp gave me fundamentals, but I learned React by building production systems at Nurtur starting July 2022.

My learning approach is goal-driven and hands-on. I don't learn technologies in the abstract. I identify a project I want to build, then learn what I need to build it. The Integrations Dashboard was my first major React project at Nurtur - I learned Redux, TypeScript integration, and production patterns while building something the sales team would use daily. The system has run 3+ years with zero maintenance, proving the learning was solid.

I teach myself fundamentals first, then build something real immediately. I learn far more from encountering real problems than from tutorials. For React specifically: I learned component thinking, state management patterns, hooks architecture, and performance optimization through building dashboards at production scale. The Nexus Dashboard taught me microfrontends and Module Federation. The Email Editor taught me Lexical framework integration.

I learn by doing, not by reading. I read enough to start, then build. When I get stuck, I consult documentation, search for solutions, or ask teammates. This hands-on approach means every skill has immediate practical application.
