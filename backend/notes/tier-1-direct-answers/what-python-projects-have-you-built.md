# What Python projects have you built?

I've built three production Python projects, all with AI/ML at the core.

WhatNow is an AI-powered activity recommendation system. Python backend with FastAPI, contextual bandits and reinforcement learning, semantic embeddings, and a two-layer learning architecture. Production-deployed on Render, and I use it in daily life.

moh-ami is a French learning translation tool with LLM integration. I designed structured prompts that produce consistent JSON outputs for word-by-word mappings, grammar explanations, and cultural context. Full-stack with Next.js frontend and GraphQL API; Python powers the LLM integration. Deployed on Railway.

Folio is the RAG-powered portfolio chatbot you're talking to now. Python backend with FastAPI and LangChain for RAG orchestration - retrieval, prompt construction, response generation. Uses embeddings and vector similarity for the knowledge base.

All three are production applications. WhatNow and moh-ami are live with public links; Folio is the system serving this conversation.
