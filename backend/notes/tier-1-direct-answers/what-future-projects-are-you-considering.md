# What future projects are you considering?

I'm becoming more active in a few online communities and considering what tools I can make to help them. I want to build products with a full user flow and improve them with every bit of feedback from the people using them.

That direction fits how I've always worked. WhatNow came from a practical problem - I needed better activity suggestions and built a system that learns from my choices. moh-ami came from helping a friend learn French. Folio came from needing a conversational portfolio for job applications. Each project started with a real user and a real need.

In the next few years I want to keep building AI-powered web applications that solve real problems - intelligent search, personalized recommendations, LLM-powered features that enhance user experiences. I'm drawn to projects where I can deliver full user flow, iterate based on feedback, and help the people around me.
